# [BOF Track] Level 1: 기초 (Intro) - `bof_intro`

## 1. 문제 개요
스택 버퍼 오버플로우의 가장 기초적인 원리인 **로컬 변수 덮어쓰기(Local Variable Corruption)**를 체험하는 문제입니다.

---

## 2. 취약점 분석
```c
volatile int is_admin = 0;
char buffer[16];
read(0, buffer, 64);   // 16바이트 버퍼에 64바이트까지 입력 허용
```
- `buffer`의 크기는 16바이트이지만, `read()`로 64바이트까지 입력을 받습니다.
- 버퍼를 넘겨 입력하면 스택 상 인접한 `is_admin` 변수가 덮어써져 관리자 인증을 통과할 수 있습니다.

---

## 3. 공략 방향 (직접 수행)
- 프로그램은 실행 시 `buffer`와 `is_admin`의 **주소를 출력**합니다. 두 주소의 **차이**를 계산하면 `is_admin`을 덮는 데 필요한 입력 길이를 구할 수 있습니다.
- 필요하면 `gdb`로 두 변수의 스택 오프셋을 직접 확인하세요.
- 완성 페이로드/명령은 제공하지 않습니다 — 위 정보로 직접 구성하세요.

---

## 4. 플래그
- `is_admin != 0` 조건을 만족하면 성공 메시지와 함께 화면에 출력됩니다. (형식: `FLAG{...}`)
